# Clases Juan Paulo

Este sitio web está diseñado para proporcionar información sobre las clases ofrecidas por Juan Paulo. La estructura del sitio se basa en HTML5 y CSS3, asegurando una experiencia de usuario responsiva y accesible.

## Características

- **Diseño Responsivo**: Adaptable a diferentes dispositivos y tamaños de pantalla.
- **Contenido Dinámico**: Integración de JavaScript para interactividad.
- **Optimización SEO**: Estructura HTML semántica para mejorar la visibilidad en motores de búsqueda.

## Instalación

Para ejecutar este sitio localmente, clone el repositorio y abra el archivo `index.html` en su navegador.
